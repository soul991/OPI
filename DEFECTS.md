# DEFECTS.md - Single Register of Known Problems (all phases)

> Rules: IDs are never reused or deleted. Every phase starts by reading this file and ends by updating it. Status values: `OPEN`, `PARTIAL`, `FIXED`, `ACCEPTED` (a known limitation that is documented in README), `DEFERRED` (scheduled for a later phase). `FIXED` requires a regression test written as `tests/<file>.py::<test_name>` that exists and passes (checked by `scripts/verify_all.py`). Severity: `Critical` (results may be invalid), `High` (wrong data or misleading claim), `Medium`, `Low`. Any `Critical` or `High` item that is `OPEN` or `PARTIAL` blocks new feature work.
